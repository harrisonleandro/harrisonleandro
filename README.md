## Projetos em destaque

### [SchemToCreate](https://github.com/harrisonleandro/SchemToCreate)

Conversor de esquemáticos do Minecraft: transforma arquivos Sponge Schematic (`.schem`), gerados pelo WorldEdit, em estruturas (`.nbt`) compatíveis com o mod Create. Funciona offline, como aplicativo desktop ou pela linha de comando.

- Codec NBT próprio, sem dependências externas, com leitura em streaming para esquemáticos de milhões de blocos
- Suíte de testes automatizados com JUnit 5 e AssertJ, incluindo conversões de ponta a ponta e execução com memória limitada
- Executável para Windows gerado com jpackage e publicado automaticamente pelo GitHub Actions a cada nova versão
- Documentação técnica detalhada: formatos de arquivo, decisões de projeto e limitações conhecidas

`Java 17` `Gradle` `picocli` `Swing` `JUnit 5` `GitHub Actions` · [Releases](https://github.com/harrisonleandro/SchemToCreate/releases) · Licença MIT
